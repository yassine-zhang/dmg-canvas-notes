Disk Image Options

Disk Image Options

Among the options for the disk image’s volume include:

  • The volume’s name
  • The volume’s icon (as shown when it is mounted)
  • The file system format (APFS for HFS+)
  • The capacity of the volume.
  • Encryption (None, AES 128, or AES 256)
  • Compression

You can customize any of these settings or use the automatic default values.
